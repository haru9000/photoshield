# フォトシールド / PhotoShield

Windows 10/11（64bit）向けの無料写真プライバシー保護ツールです。
ZIPを展開し、PhotoShield/PhotoShield.exe を起動してください。
_internal フォルダを含むフォルダ一式を保管してください。Pythonは不要です。

画像タブから画像を追加すると、顔・QRコード・日本語の個人情報文字・
ナンバープレートを自動検出し加工します。サンプル画像追加ボタンで試せます。
範囲を編集タブでは矩形・楕円・台形・フリーハンドで追加・調整できます。
領域を右クリックすると加工方法やスタンプを変更でき、ゴミ箱で削除できます。
上部アイコンで現在画像／全画像の別名保存と比較表示を選びます。
現在画像の保存は名前・場所・PNG/JPEG/TIFF形式を選べます。
既存の出力は確認後に置き換えられますが、読み込んだ元画像は上書きできません。
全画像保存ではフォルダと形式を選び、連番で別名保存します。メタデータは引き継ぎません。
Ctrl+O: 画像追加 / Ctrl+S: 現在画像保存 / Ctrl+Shift+S: 全画像保存
Ctrl+Z: 取り消し / Ctrl+Y: やり直し

解析・加工・保存はPC内で完結し、外部API、写真の送信、アクセス解析はありません。
自動検出には見落としがあります。保存前に目視確認してください。
ぼかし・モザイクは情報が残る場合があります。
本アプリは未署名のためWindowsの警告が表示されることがあります。

ソースはsource/、ライセンスと取得元はthird-party-licenses/とMODELS.mdです。
第三者ライブラリには各ライセンスが適用されます。
互換ライブラリの置換や変更を妨げる制限は設けていません。
ソースの実行: Python 3.12で source/requirements.txt をインストールし main.py を実行。
ビルド: PyInstallerをインストールし source/ で pyinstaller PhotoShield.spec を実行。
